📖 How to Import Documents

1

Create a CSV file

Use any spreadsheet software (Excel, Google Sheets, Numbers, etc.) to create a CSV file. Your file must have these two columns:

title expiry_date
Driver's License 2028-06-15
Business Insurance 2027-03-01
Passport 2030-12-01

💡 Column name variations accepted: "title", "document", "document_title", "doc_title", "name" — "expiry_date", "expiry", "expiration", "expiration_date"

2

Export as CSV

From Excel: File → Save As → Choose "CSV (Comma delimited)"

From Google Sheets: File → Download → Comma Separated Values (.csv)

From Numbers: File → Export To → CSV

⚠️ Important: Your CSV must use commas as separators, not semicolons.

3

Upload your file

Use the form above to upload your CSV file. We'll import all your documents automatically. Any rows with missing information or invalid dates will be skipped.

✅ Accepted date formats: YYYY-MM-DD, DD/MM/YYYY, MM/DD/YYYY

💡 Tips for a Smooth Import

  • Make sure every document has a title and expiry_date
  • Use YYYY-MM-DD format (e.g., 2028-06-15) for best results
  • Avoid extra columns — we only use "title" and "expiry_date"
  • If you have many documents, you can import them in batches
  • Duplicates won't be created — if a document already exists, it will be skipped
  • Maximum 5MB file size
